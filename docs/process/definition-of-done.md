# Definition of Done (DoD)

Un cambio se considera Done solo si:

1. Requisito y criterio de aceptacion estan actualizados.
2. Codigo implementa exactamente el comportamiento esperado.
3. Pruebas relevantes pasan en harness.
4. Evidencia esta disponible y trazada a commit/PR.
5. Documentacion de decision (ADR) existe cuando aplica.
6. Riesgos residuales y limites estan explicitados.

## Regla de bloqueo

Si falta cualquiera de los puntos anteriores, el cambio no esta Done.
