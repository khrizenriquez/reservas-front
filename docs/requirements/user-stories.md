# User Stories Base

Esta plantilla sirve para iniciar un proyecto nuevo replicando la disciplina actual.

## Formato recomendado

- ID: US-XXX
- Titulo: breve y verificable
- Como [rol], quiero [capacidad], para [valor]
- Criterios de aceptacion: referencia a scenario IDs
- Riesgos y supuestos

## Historias semilla sugeridas

- US-001: Como persona usuaria, quiero comprender el servicio y sus limites desde la landing.
- US-002: Como persona usuaria, quiero iniciar flujo de acceso segun contrato vigente.
- US-003: Como persona usuaria, quiero completar flujos de gestion operativa definidos por spec.
- US-004: Como equipo, queremos que cambios funcionales tengan trazabilidad completa y evidencia.
