# Release Evidence Checklist

## Checklist por release

- [ ] Especificacion actualizada (si hubo cambio funcional).
- [ ] ADR actualizado/creado (si hubo cambio de decision estructural).
- [ ] Matriz de trazabilidad cerrada.
- [ ] Verificacion de contrato aprobada.
- [ ] Pruebas unitarias/integracion aprobadas.
- [ ] Pruebas E2E requeridas aprobadas.
- [ ] Evidencia manual adjunta cuando aplique (accesibilidad/revision humana).
- [ ] Riesgos residuales documentados.

## Metadatos minimos

- Commit SHA
- Fecha/hora
- Entorno
- Perfil de ejecucion
- Enlaces a reportes
